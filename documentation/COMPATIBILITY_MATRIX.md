## Declared onboarding profiles

Canonical setup accepts `safe`, `standard`, `full`. `safe` is the default and exposes a read-only `core` surface with project mutators omitted. `standard` uses the complete `core` surface. `full` enables `all` toolsets. `--toolsets` overrides `standard` or `full`; safe accepts only `core`.

Supported explicit toolsets: `assets`, `bridge`, `core`, `docs`, `events`, `maintenance`, `resourcetool`, `rooms`, `runtime`, `texture-groups`, or `all`.
